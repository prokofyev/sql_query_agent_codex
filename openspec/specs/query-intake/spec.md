# query-intake Specification

## Purpose

Определяет, как SQL-запрос попадает в систему: из библиотеки предустановленных примеров или вводом
пользователя, и какие запросы вообще принимаются к обработке.

## Requirements

### Requirement: Предустановленная библиотека запросов

Система SHALL предоставлять набор предустановленных демонстрационных запросов с описанием ожидаемого
эффекта индекса. Набор MUST включать не менее пяти запросов: как минимум три, где индекс даёт заметное
ускорение, и как минимум два, где индекс не помогает, причём по разным причинам (низкая селективность
колонки и узкое место в соединении или агрегации).

#### Scenario: Пользователь выбирает предустановленный запрос
- **WHEN** пользователь выбирает запрос из библиотеки
- **THEN** система подставляет его текст в поле ввода
- **AND** запрос готов к отправке без ручного редактирования

#### Scenario: Библиотека покрывает случаи «индекс не помогает»
- **WHEN** система запускает предустановленный запрос, для которого индекс не даёт ускорения
- **THEN** результат прогона сообщает об отсутствии значимого ускорения
- **AND** причина отсутствия ускорения объясняется пользователю

### Requirement: Свободный ввод запроса

Система SHALL принимать произвольный SQL-запрос, введённый пользователем, включая запросы, которых нет
в предустановленной библиотеке.

#### Scenario: Пользователь вводит свой запрос
- **WHEN** пользователь вводит собственный SQL-запрос и отправляет его
- **THEN** система обрабатывает его так же, как предустановленный
- **AND** библиотека запросов не изменяется

### Requirement: Ограничение принимаемых запросов

Система SHALL принимать к обработке только одиночный запрос на чтение (`SELECT` или `WITH`).
Система MUST отклонять пустой ввод, несколько команд в одном вводе и команды, изменяющие данные или
схему.

#### Scenario: Пустой ввод
- **WHEN** пользователь отправляет пустое поле или строку из пробелов
- **THEN** система не запускает обработку
- **AND** сообщает, что запрос не задан

#### Scenario: Несколько команд в одном вводе
- **WHEN** ввод содержит более одной SQL-команды
- **THEN** система отклоняет ввод
- **AND** сообщает, что допускается только один запрос

#### Scenario: Команда, изменяющая данные
- **WHEN** ввод содержит команду, изменяющую данные или схему
- **THEN** система отклоняет ввод
- **AND** сообщает, что принимаются только запросы на чтение
