## MODIFIED Requirements

### Requirement: Библиотека запросов, ускоряемых индексом

Система SHALL брать библиотеку предустановленных демонстрационных запросов из внешнего файла, а не
из исходного кода. Каждый запрос SHALL иметь подпись и пояснение. Библиотека MUST включать не менее
десяти реалистичных запросов и SHALL покрывать разные формы выборки: точечный фильтр, выборку с
сортировкой и ограничением, фильтр по списку значений, сравнение диапазона, соединение двух и трёх
таблиц, агрегат и оконную функцию. Каждый запрос набора SHALL ускоряться созданием индекса на
демонстрационной базе: библиотека MUST NOT содержать примеров, для которых индекс не даёт ускорения.
Библиотека SHALL содержать запросы, ускоряемые разными индексами, а не одним и тем же. Описание
пресета MUST NOT содержать команду создания индекса.

#### Scenario: Пользователь выбирает предустановленный запрос
- **WHEN** пользователь выбирает запрос из библиотеки
- **THEN** система подставляет его текст в поле ввода
- **AND** запрос готов к отправке без ручного редактирования

#### Scenario: Каждый пресет ускоряется индексом
- **WHEN** система запускает предустановленный запрос на демонстрационной базе
- **THEN** предложенный индекс даёт значимое ускорение замера
- **AND** библиотека не содержит запросов, которые индекс не ускоряет

#### Scenario: Библиотека покрывает разные формы выборки
- **WHEN** пользователь просматривает список предустановленных запросов
- **THEN** среди них есть запросы с фильтром, сортировкой, диапазоном, соединением, агрегатом и
  оконной функцией
- **AND** запросы отличаются по форме, а не только по значениям в условии

#### Scenario: Библиотека использует разные индексы
- **WHEN** система запускает разные предустановленные запросы на демонстрационной базе
- **THEN** как минимум два запроса ускоряются индексами по разным колонкам
- **AND** библиотека не сводится к примерам с одним и тем же рычагом оптимизации

#### Scenario: Описание пресета не задаёт индекс
- **WHEN** система отдаёт библиотеку пресетов внешнему клиенту
- **THEN** каждый пресет содержит подпись, текст запроса и пояснение
- **AND** команда создания индекса в описании пресета отсутствует

#### Scenario: Библиотека берётся из внешнего файла
- **WHEN** система загружает библиотеку предустановленных запросов
- **THEN** источником служит внешний файл, путь к которому задан настройкой
- **AND** изменение файла меняет состав библиотеки без правки исходного кода

#### Scenario: Файл библиотеки отсутствует или пуст
- **WHEN** внешний файл с библиотекой отсутствует или не содержит запросов
- **THEN** система продолжает работать
- **AND** библиотека предустановленных запросов пуста

#### Scenario: Файл библиотеки содержит повреждённую запись
- **WHEN** запись в файле библиотеки лишена обязательного поля
- **THEN** система сообщает об ошибке загрузки библиотеки
- **AND** не подставляет пользователю повреждённый запрос
