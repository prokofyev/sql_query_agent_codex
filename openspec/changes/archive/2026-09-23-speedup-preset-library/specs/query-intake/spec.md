## REMOVED Requirements

### Requirement: Предустановленная библиотека запросов

**Reason**: Требование мандатировало примеры без ускорения и описание ожидаемого эффекта; библиотека
переходит на примеры, которые все ускоряются индексом, а ожидаемый эффект и команда индекса из
описания пресета убираются.

**Migration**: Случай «индекс не помогает» остаётся обязательным для свободного ввода в требовании
`index-optimization`; демонстрация переходит на произвольный запрос пользователя. Прежние примеры
заменяются новой библиотекой.

## ADDED Requirements

### Requirement: Библиотека запросов, ускоряемых индексом

Система SHALL предоставлять набор предустановленных демонстрационных запросов с подписью и пояснением
к каждому. Набор MUST включать не менее десяти реалистичных запросов, и SHALL покрывать разные формы
выборки: точечный фильтр, выборку с сортировкой и ограничением, фильтр по списку значений, соединение
двух и трёх таблиц, агрегат и оконную функцию. Каждый запрос набора SHALL ускоряться созданием индекса
на демонстрационной схеме: библиотека MUST NOT содержать примеров, для которых индекс не даёт
ускорения. Описание пресета MUST NOT содержать команду создания индекса.

#### Scenario: Пользователь выбирает предустановленный запрос
- **WHEN** пользователь выбирает запрос из библиотеки
- **THEN** система подставляет его текст в поле ввода
- **AND** запрос готов к отправке без ручного редактирования

#### Scenario: Каждый пресет ускоряется индексом
- **WHEN** система запускает предустановленный запрос на демонстрационной базе
- **THEN** предложенный индекс даёт значимое ускорение замера
- **AND** библиотека не содержит запросов, которые индекс не ускоряет

#### Scenario: Библиотека покрывает разные формы выборки
- **WHEN** пользователь просматривает список предустановленных запросов
- **THEN** среди них есть запросы с фильтром, сортировкой, соединением, агрегатом и оконной функцией
- **AND** запросы отличаются по форме, а не только по значениям в условии

#### Scenario: Описание пресета не задаёт индекс
- **WHEN** система отдаёт библиотеку пресетов внешнему клиенту
- **THEN** каждый пресет содержит подпись, текст запроса и пояснение
- **AND** команда создания индекса в описании пресета отсутствует
