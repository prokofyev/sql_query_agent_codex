## MODIFIED Requirements

### Requirement: Ввод запроса

Веб-интерфейс SHALL предоставлять поле ввода SQL-запроса и список предустановленных запросов. Поле
ввода MUST быть доступно и после завершения предыдущего прогона, включая случаи отказа пользователя.
Вверху страницы, перед полем ввода, интерфейс SHALL показывать панель схемы базы, если схема задана
внешним файлом.

#### Scenario: Поле ввода доступно при открытии
- **WHEN** пользователь открывает интерфейс
- **THEN** отображается поле ввода запроса
- **AND** отображается список предустановленных запросов

#### Scenario: Библиотека пресетов пуста
- **WHEN** внешний файл с библиотекой пресетов отсутствует или не содержит запросов
- **THEN** интерфейс открывается без ошибки
- **AND** поле ввода доступно для ручного ввода запроса

#### Scenario: Возврат к вводу после отказа
- **WHEN** пользователь отказался от исправления запроса
- **THEN** поле ввода снова доступно
- **AND** пользователь может ввести новый запрос без перезагрузки страницы

#### Scenario: Ввод недоступен во время обработки
- **WHEN** обработка запроса выполняется
- **THEN** повторная отправка блокируется
- **AND** пользователю видно, что запрос обрабатывается

## ADDED Requirements

### Requirement: Панель схемы базы

Вверху страницы интерфейса, перед полем ввода, интерфейс SHALL показывать схему базы данных: список
столбцов каждой таблицы, связи между таблицами и число строк у каждой таблицы. Схема SHALL
отображаться в виде псевдографики и SHALL браться из внешнего файла, а не запрашиваться у базы.
Отсутствующий, пустой или повреждённый файл схемы MUST NOT мешать открытию интерфейса и вводу
запроса.

#### Scenario: Схема показана при открытии
- **WHEN** пользователь открывает интерфейс и внешний файл схемы задан
- **THEN** вверху страницы показана схема базы
- **AND** схема содержит таблицы, их столбцы и число строк
- **AND** схема показана выше поля ввода

#### Scenario: Связи между таблицами видны
- **WHEN** пользователь просматривает схему
- **THEN** на схеме видны связи между таблицами через колонки-ключи
- **AND** направление связи позволяет понять, какая таблица ссылается на какую

#### Scenario: Файл схемы отсутствует или пуст
- **WHEN** внешний файл схемы отсутствует или не содержит схемы
- **THEN** интерфейс открывается без ошибки
- **AND** поле ввода доступно для ручного ввода запроса
- **AND** пустая панель схемы не занимает место на странице

#### Scenario: Файл схемы повреждён
- **WHEN** внешний файл схемы не удаётся прочитать или в нём нет обязательного содержимого
- **THEN** интерфейс открывается без ошибки
- **AND** поле ввода доступно для ручного ввода запроса
- **AND** повреждённая схема не показывается частично
