## MODIFIED Requirements

### Requirement: Однократное исправление запроса

Модель SHALL один раз исправить исходный запрос, опираясь на предложенных кандидатов и сведения о
неоднозначности, и только если для каждого ненайденного имени есть хотя бы один кандидат на замену.
Модель MUST NOT придумывать имена, которых нет среди предложенных кандидатов. Повторная проверка
исправленного запроса MUST NOT запускаться автоматически.

Исправленный запрос SHALL приводиться к исполнимому виду: если модель вернула переносы строк
экранированными, система SHALL восстановить их перед показом запроса пользователю и перед замером.
Восстановление MUST NOT затрагивать текст внутри строковых литералов и кавычек-идентификаторов.
Запрос, в котором переносы уже настоящие, MUST NOT изменяться.

#### Scenario: Модель исправляет опечатки
- **WHEN** инструмент вернул ненайденные имена и для каждого из них есть кандидаты на замену
- **THEN** модель возвращает исправленный текст запроса
- **AND** показывает пользователю, какие имена были заменены

#### Scenario: Модель исправляет и таблицу, и колонку
- **WHEN** среди ненайденных имён есть и таблица, и колонка этой таблицы, и для обоих имён есть кандидаты
- **THEN** исправленный запрос содержит замену обоих имён
- **AND** пользователю показаны обе замены

#### Scenario: Исправление не повторяется автоматически
- **WHEN** модель выдала исправленный запрос
- **THEN** система не запускает ещё один цикл исправления
- **AND** решение передаётся пользователю

#### Scenario: Исправление не выполняется без кандидатов
- **WHEN** хотя бы для одного ненайденного имени нет кандидатов выше порога схожести
- **THEN** модель не вызывается для исправления
- **AND** исходный запрос не изменяется

#### Scenario: Переносы строк в исправленном запросе
- **WHEN** модель вернула исправленный запрос с экранированными переносами строк
- **THEN** пользователю показывается запрос с настоящими переносами
- **AND** запрос в таком виде исполним

#### Scenario: Переносы внутри строкового литерала
- **WHEN** экранированный перенос встречается внутри строкового литерала
- **THEN** текст литерала не изменяется
- **AND** значение литерала остаётся прежним

#### Scenario: Запрос уже с настоящими переносами
- **WHEN** модель вернула запрос с настоящими переносами строк
- **THEN** текст запроса не изменяется
