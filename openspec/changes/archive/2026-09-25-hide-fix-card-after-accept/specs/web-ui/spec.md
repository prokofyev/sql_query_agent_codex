## MODIFIED Requirements

### Requirement: Отображение предложения об исправлении

Интерфейс SHALL показывать исправленный запрос и список выполненных замен, а также предоставлять
элементы управления для принятия и отказа, пока предложение ждёт решения. После принятия исправления
интерфейс MUST NOT показывать ни исправленный запрос как предложение, ни список замен: дальше
система обрабатывает принятый запрос, и он остаётся видимым в поле ввода. При отказе предложение
остаётся видимым: пользователю может понадобиться увидеть, что именно предлагалось.

#### Scenario: Показано предложение об исправлении
- **WHEN** модель исправила имена в запросе
- **THEN** интерфейс показывает исправленный запрос
- **AND** показывает, какие имена были заменены
- **AND** доступны действия «принять» и «отказаться»

#### Scenario: Исправление принято
- **WHEN** пользователь принимает предложенное исправление
- **THEN** предложение и список замен больше не показываются
- **AND** принятый запрос остаётся видимым в поле ввода

#### Scenario: Предложение об исправлении отклонено
- **WHEN** пользователь отказывается от предложенного исправления
- **THEN** предложение и список замен остаются видимыми

### Requirement: Отображение хода длительной операции

Интерфейс SHALL показывать, что запрос обрабатывается, пока система выполняет работу: отправку
запроса, обработку решения пользователя или создание индекса. Пока обработка идёт, интерфейс MUST NOT
показывать статус ожидания решения пользователя. По завершении интерфейс SHALL показывать результат.

#### Scenario: Создание индекса выполняется
- **WHEN** система применяет индекс к большой таблице
- **THEN** интерфейс показывает признак выполняющейся операции
- **AND** по завершении показывает результат

#### Scenario: Решение пользователя обрабатывается
- **WHEN** пользователь принял или отклонил предложение
- **THEN** пока система обрабатывает решение, интерфейс показывает, что запрос обрабатывается
- **AND** статус ожидания решения в это время не показывается
