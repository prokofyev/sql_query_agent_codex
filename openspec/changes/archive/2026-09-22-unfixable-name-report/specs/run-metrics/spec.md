## ADDED Requirements

### Requirement: Журнал прогонов без замен имён

Система SHALL сохранять прогон, завершившийся из-за отсутствия замен для ненайденных имён, как
запись журнала обычного завершённого прогона. Запись MUST содержать ненайденные имена и MUST NOT
содержать признак сбоя обработки. Метрики процесса MUST относить такой прогон к завершённым.

#### Scenario: Прогон без замен записан в журнал
- **WHEN** прогон завершился из-за отсутствия замен для ненайденных имён
- **THEN** в журнал добавляется запись с ненайденными именами
- **AND** запись не содержит ошибки обработки

#### Scenario: Метрика относит прогон к завершённым
- **WHEN** прогон завершился из-за отсутствия замен для ненайденных имён
- **THEN** счётчик прогонов увеличивается
- **AND** замеры длительности в гистограмму не попадают, поскольку замер не выполнялся
