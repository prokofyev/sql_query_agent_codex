# SQL Index Advisor

LLM-агент на LangGraph: проверяет имена таблиц и колонок в SQL-запросе по реальной схеме
базы, исправляет опечатки с подтверждением человеком (HITL) и проверяет гипотезу об индексе —
создаёт индекс в транзакции, повторно замеряет запрос и откатывает транзакцию.

## Что делает

1. Модель извлекает из запроса имена таблиц и колонок и передаёт их инструменту `check_schema`.
2. Инструмент сверяет имена с `information_schema` и подбирает похожие через `rapidfuzz`.
3. При опечатках модель правит запрос, а пользователь принимает или отклоняет правку. Если похожих
   имён не нашлось и заменять нечем, система сообщает, какие имена не найдены, и завершает сессию —
   модель ничего не придумывает, замер не выполняется.
4. Запрос замеряется в read-only транзакции: прогрев, несколько повторов, медиана.
5. Модель предлагает `CREATE INDEX`; при согласии инструмент создаёт индекс в транзакции, повторно
   замеряет запрос и откатывает транзакцию. База остаётся в исходном состоянии.
6. Итог прогона пишется в audit-журнал схемы `metrics`, а счётчики и гистограммы отдаются на
   `/metrics` в формате Prometheus.

Отсутствие ускорения — полноценный результат, а не ошибка: если индексу не за что зацепиться,
агент сообщит об этом и укажет причину.

## Требования

- Python 3.13+, [uv](https://docs.astral.sh/uv/).
- PostgreSQL с ролью, у которой есть право `CREATE`.
- Креденшелы GigaChat для обращений к модели.

## Настройка

```bash
uv sync
cp .env.example .env
```

Заполните `.env`:

- `SQA_DATABASE__DSN` — строка подключения к базе;
- `SQA_GIGACHAT__CREDENTIALS` — ключ авторизации GigaChat;
- при необходимости `SQA_GIGACHAT__VERIFY_SSL=false` для локального стенда и
  `SQA_GIGACHAT__MODEL` для выбора модели;
- при необходимости `SQA_PRESETS__PATH` — библиотека предустановленных запросов (по умолчанию
  `resources/presets.yaml`);
- при необходимости `SQA_SCHEMA__PATH` — схема базы для панели интерфейса (по умолчанию
  `resources/schema.yaml`).

Схемы `agent` (checkpoint'ы LangGraph) и `metrics` (журнал прогонов) создаются автоматически при
запуске.

## Запуск

```bash
uv run sql-index-advisor --host 127.0.0.1 --port 8080
```

- Веб-интерфейс: `http://127.0.0.1:8080/ui/`
- API: `POST /runs`, `POST /runs/{thread_id}/decision`, `GET /runs`, `GET /runs/{thread_id}`,
  `GET /presets`, `GET /schema`, `GET /metrics`, `GET /healthz`

## Тесты

```bash
uv run pytest -q                  # быстрые тесты без базы и модели
uv run pytest -q -m integration   # тесты на реальной базе
uv run pytest -q --run-llm        # тесты с реальной моделью GigaChat
uv run ruff check src tests
```

Интеграционные тесты пропускаются, если база недоступна, а тесты с моделью — без флага `--run-llm`.
